# 项目概览

## SemAdExp：LLM 语义增强的双边市场实验智能平台

**定位**：面向广告平台双边市场实验的"假设生成 → 反事实均衡仿真 → 语义竞争分桶 → 效果估计 → 归因与剥离 → 知识回流"闭环实验智能平台，四层全部量化验证。

**解决的问题**：

| 问题 | 解决方案 | 量化证据（固定种子可复现） |
|---|---|---|
| 效果衡量准确性 | 自建带 ground truth 的仿真器 + 干扰感知估计器 + 效应剥离 | 竞争图谱分桶使最严苛场景 bias 降 66%、RMSE 降 59%；间接效应均值恢复误差 ≈ 0 |
| 广告主异质性干扰 | LLM 语义竞争图谱 + 群落随机化分桶 | 跨组强竞争边占比 0.525 → 0.255，采样稳定性显著提升 |
| 特征滞后、增量信息 | 结构化语义标签 + 语义向量融合行为特征 | AUC +0.043、熵增益 +0.014 nats（5 折交叉验证） |
| 迭代效率 | LLM 假设生成 + 优先级排序 | Top-8 机会召回率 100%，50% 价值捕获 1 个实验 vs 随机基线 20 个 |

**工程亮点**：

- 双边市场仿真器：预算竞争、用户疲劳、供给替代、广告主流失，支持一价/GSP 拍卖与真值反事实运行；
- LLM 双后端：OpenAI API（gpt-4o-mini + text-embedding-3-small）与确定性离线后端等价切换，全量哈希缓存、成本日志与 $20 预算上限，离线可复现；
- 工程化：CLI（8 个子命令）、pydantic 配置契约、10 个自动化测试、固定种子复现、一键生成中文技术报告与 5 张图表；
- 5 个叙事性 Notebook 覆盖全链路，可直接作为项目演示素材。

**主要产物**：可运行 Python 工程、5 个 Notebook、中文技术报告（`results/technical_report.md`）、场景矩阵 CSV、假设排序与捕获曲线数据。

**诚实性声明**：广告文案/操作日志/工单/复盘为受控生成语料，知识库真值来自仿真器；真实部署需接入线上数据。该声明作为方法论严谨性的组成部分保留在报告中。

**快速复现**：`python -m venv .venv && .venv/bin/pip install -r requirements.txt && .venv/bin/python -m semadexp.cli run-all --scale full`
