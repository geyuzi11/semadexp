# 常见问题（FAQ）

## LLM 语义特征的必要性怎么证明？

消融实验：行为特征 AUC 0.629，融合后 0.672，熵增益 +0.014 nats；且语义特征直接驱动图谱分桶，后者把 bias 减半以上——不是"锦上添花"，是全链路依赖。

## CUPED 在结果里效果不明显？

对，这正是一个有信息量的发现：CUPED 的增益取决于预实验协变量与结果的相关性；在烧机期协变量强相关时它显著收窄置信区间，否则不改变点估计。报告里如实呈现，没有美化。

## 覆盖率 1.0 但功效低，是不是没用？

随机化推断把推断单元放在群落层，保守是它的性质；它的价值是在干扰下给出**校准可信**的区间，与点估计有偏的 Wald 区间形成对照。工程上两者结合使用。

## 为什么不用公开数据集？

公开点击日志没有双边市场干扰结构，也没有策略干预的 ground truth；本项目的策略是"公开行为基线 + 自建市场仿真"双轨，README 中说明了替换 Criteo 的接入方式。

## 如何接入真实数据？

1. 将 Criteo 数据放入 `data/criteo/train.txt`，调用 `load_criteo_sample()` 接入行为基线；
2. 设置 `OPENAI_API_KEY` 后语义提取自动切换到真实模型（gpt-4o-mini + text-embedding-3-small）；
3. 将广告主操作日志、工单、复盘文档替换为线上数据，知识库真值可改为历史实验记录。

## 成本控制怎么做？

所有 LLM 输出按 prompt 哈希缓存到 `data/cache/`，二次运行完全离线；成本记录在 `data/cache/llm_cost.csv`，默认预算上限 $20，超出即停止。
