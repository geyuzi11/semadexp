本报告围绕一个核心命题：广告平台的双边市场特性使实验面临跨侧干扰与广告主异质性，传统统计方法难以准确衡量策略效果；将 LLM 语义信息贯穿实验全链路可以显著提升衡量的准确性、稳定性与迭代效率。

所有结论均来自固定随机种子下的可复现运行（full 规模），数值与代码仓库中的 `results/` 产物完全一致；方法、假设与局限性在报告中如实披露。

2　研究问题与贡献

挑战 1 · 衡量准确性

跨组预算挤占与流量转移使实验效果并非策略本身的效果；传统置信区间在干扰下大面积失准（覆盖率最低 0.0–0.1）。

挑战 2 · 广告主异质性

传统按预算/行业分层无法捕捉细粒度竞争关系，采样稳定性受强竞争广告主跨组分流影响。

挑战 3 · 特征滞后

结构化行为特征维度有限；广告文案、操作日志等非结构化数据蕴含大量未被利用的语义增量信息。

挑战 4 · 迭代效率

人工驱动假设受经验盲区限制；缺少量化的实验优先级排序，高成本低收益实验频发。

本平台的贡献：构建闭环系统，将 LLM 语义能力应用于（a）从非结构化语料生成可验证实验假设并量化排序；（b）生成广告主策略响应假设驱动反事实均衡模拟；（c）构建广告主竞争语义图谱实现竞争感知分桶；（d）驱动预测增强估计、异质性归因与内生干扰剥离。四个层级的增益均有真值对照下的量化证据。

4　数据与 LLM 语义层

全部语料由固定种子受控生成（广告文案 8 品类、操作日志、工单、复盘文档），行为基线默认离线合成、可替换 Criteo。LLM 双后端保证：设置 OPENAI_API_KEY 后使用 gpt-4o-mini + text-embedding-3-small；未设置时确定性离线后端输出等价 JSON 契约。全部输出按 prompt 哈希缓存，成本日志记录并设 $20 预算上限。

结论：在 5 折交叉验证下，融合 LLM 语义特征后 AUC 提升 +0.0428、对数损失下降、熵增益 +0.0143 nats——语义特征携带行为特征之外的增量信息，可用于更精细的分层与预测调整（特征维度：行为 7，语义 21）。

5　仿真器与真值构建

市场主体

广告主（档位/预算/出价/质量分/文案语义/转化价值）× 用户（品类兴趣/会话疲劳/负反馈）× 拍卖（一价默认、GSP 可配置、softmax 候选随机化）。

干扰机制

预算竞争、用户广告疲劳、供给替代、广告主流失；策略干预支持竞价门槛、广告条数上限、拍卖规则、预算乘数。

真值结构

对同一策略运行三组全局反事实市场：C（控制）、T0（策略无响应）、T1（策略+广告主响应）。直接效应 = T0−C，间接效应 = T1−T0。

机制验证：预算约束恒成立；无策略时真值效应收敛于 0（无偏性 sanity）；策略变化方向与市场直觉一致（如提高竞价门槛降低总消耗）。这保证后续所有估计器都能对真值计算 bias / RMSE / 覆盖率 / 功效，而非停留在“看起来更准”。

13　局限性与结论

语料近似

广告文案/操作日志/工单/复盘为受控生成语料；知识库真值来自仿真器而非线上。

模型简化

拍卖与用户模型为简化机制（一价默认/GSP 可配置），未包含多槽位、竞价调优等。

样本规模

场景矩阵重复实验数与知识库规模（60 个历史实验）可进一步放大以获得更紧置信区间。

结论：证据链表明——LLM 语义特征提供增量信息；竞争图谱分桶从源头削减跨组干扰；干扰感知估计与效应剥离显著提升衡量可信度；反事实均衡模拟降低试错成本；假设生成层把迭代从“人工驱动”推向“数据 + AI 驱动”。方法论价值不依赖语料真实性，真实部署需接入线上数据。

附录　指标定义

  • bias：估计量跨重复实验的均值与真值直接效应之差（真值来自全局反事实市场）。
  • 方差：跨重复实验的点估计方差（抽样稳定性）。
  • RMSE：√(bias² + 方差)，综合准确性与稳定性。
  • 覆盖率：95% 置信区间包含真值的重复实验比例。
  • 功效：|估计/标准误| > 1.96 的重复实验比例（真值非零时近似功效）。
  • 熵增益：行为特征模型对数损失 − 融合模型对数损失（nats），正值表示语义特征降低预测不确定性。
  • 跨组强竞争边占比：权重超过阈值（0.3）的竞争边中跨越处理/对照组的比例。
